ComfyUI 启动命令
监听 IP
--listen，默认 127.0.0.1 (仅本机)。设为 0.0.0.0 监听所有网络接口，可局域网访问
端口
--port，ComfyUI Web 服务端口，默认 8188
自动打开浏览器
--auto-launch，启动后自动打开默认浏览器访问 WebUI
VRAM 模式
显存管理策略。高显存=模型常驻GPU；低显存=编码器放CPU；极低=极限省显存；仅GPU=全部放GPU；CPU=纯CPU慢速
预览方式
--preview-method，采样器节点的默认预览方式。auto=自动选择；latent2rgb=潜空间转RGB；taesd=TAESD快速解码；none=不预览
启用 CORS
--enable-cors-header，允许跨域资源共享。填入允许的域名，留空=禁用。设为 * 允许所有来源
额外命令行参数
其他 main.py 参数，用空格分隔，如: --force-fp16 --bf16-vae --verbose DEBUG
环境变量预设
在 ComfyUI 启动前注入 set 命令，每行为一组变量名=值，如 TORCH_COMPILE_OFF=1
示例: TORCH_COMPILE_OFF=1

显示悬浮球

写入当前用户注册表 Run 键，登录 Windows 时自动启动管理器（不弹浏览器，只出悬浮球）。下次启动管理器时生效

关机功能

默认关机延迟(秒)
点击右下角菜单的关机按钮后，等待多少秒执行关机。1-3600 = 可随时取消的倒计时；0 = 立即关机（不可取消）
退出管理器
只关闭管理器本身，不影响 ComfyUI。改过监听地址/端口后，需要退出再重新双击启动器才会生效 —— 本工具不做「一键重启」，因为 Windows 下新旧进程会同时占用同一端口
