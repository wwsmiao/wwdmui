修复区域
GitHub 镜像读取中… pip 镜像源读取中… 前往全局设置修改
修复区域里的 git / pip 操作都会使用上面这两个镜像，并在日志开头打印实际使用的源与完整命令行；镜像可用性可在全局设置中一键测试。
更新 ComfyUI
用 git 更新 ComfyUI 到最新版或切换到指定分支/标签，完成后自动用 pip 安装根目录下的 requirements.txt 依赖。
需要 ComfyUI 根目录是 Git 仓库；普通用户直接点「更新到最新版」即可。
