comfyui常用启动参数解析

在 全局设置 的「ComfyUI 启动命令」中，可在额外命令行参数填入下面的选项：

参数说明
-h, --help显示帮助信息并退出。
--listen [IP]指定监听的 IP 地址，默认 127.0.0.1；可不带参数使用，默认监听 0.0.0.0,::，即所有 IPv4/IPv6；也可用逗号分隔多个 IP，如 127.2.2.2,127.3.3.3。
--port PORT设置监听端口。
--tls-keyfile TLS_KEYFILE指定 TLS/SSL 密钥文件路径，启用 TLS 后可通过 https://... 访问，必须与 --tls-certfile 配合。
--tls-certfile TLS_CERTFILE指定 TLS/SSL 证书文件路径，启用 TLS 后可通过 https://... 访问，必须与 --tls-keyfile 配合。
--enable-cors-header [ORIGIN]启用 CORS 跨域资源共享；可指定允许的 origin，默认 * 表示允许所有。
--max-upload-size MAX_UPLOAD_SIZE设置最大上传大小，单位 MB。
--base-directory BASE_DIRECTORY设置 ComfyUI 基础目录，用于 models、custom_nodes、input、output、temp、user 等目录。
--extra-model-paths-config PATH [PATH ...]加载一个或多个 extra_model_paths.yaml 文件。
--output-directory OUTPUT_DIRECTORY设置 ComfyUI 输出目录，覆盖 --base-directory。
--temp-directory TEMP_DIRECTORY设置 ComfyUI 临时目录，默认在 ComfyUI 目录内，覆盖 --base-directory。
--input-directory INPUT_DIRECTORY设置 ComfyUI 输入目录，覆盖 --base-directory。
--auto-launch启动后自动在默认浏览器中打开 ComfyUI。
--disable-auto-launch禁用自动打开浏览器。
--cuda-device DEVICE_ID设置本实例使用的 CUDA 设备 ID，可用逗号分隔如 0 或 0,1，或 all 保留当前所有可见设备；其他设备将不可见。
--default-device DEFAULT_DEVICE_ID设置默认设备 ID，其他设备仍然可见。
--cuda-malloc启用 cudaMallocAsync，在 torch 2.0 及以上默认启用。
--disable-cuda-malloc禁用 cudaMallocAsync。
--force-fp32强制使用 fp32；如果这能让你的 GPU 工作更好，建议反馈。
--force-fp16强制使用 fp16。
--fp32-unet扩散模型/UNet 以 fp32 运行。
--fp64-unet扩散模型/UNet 以 fp64 运行。
--bf16-unet扩散模型/UNet 以 bf16 运行。
--fp16-unet扩散模型/UNet 以 fp16 运行。
--fp8_e4m3fn-unet将 UNet 权重以 fp8_e4m3fn 存储。
--fp8_e5m2-unet将 UNet 权重以 fp8_e5m2 存储。
--fp8_e8m0fnu-unet将 UNet 权重以 fp8_e8m0fnu 存储。
--fp16-vaeVAE 以 fp16 运行，可能导致黑图。
--fp32-vaeVAE 以完整精度 fp32 运行。
--bf16-vaeVAE 以 bf16 运行。
--cpu-vaeVAE 在 CPU 上运行。
--fp8_e4m3fn-text-enc文本编码器权重以 fp8 e4m3fn 变体存储。
--fp8_e5m2-text-enc文本编码器权重以 fp8 e5m2 变体存储。
--fp16-text-enc文本编码器权重以 fp16 存储。
--fp32-text-enc文本编码器权重以 fp32 存储。
--bf16-text-enc文本编码器权重以 bf16 存储。
--fp16-intermediates实验性选项，节点之间的中间张量使用 fp16 而不是 fp32。
--force-channels-last推理模型时强制使用 channels last 格式。
--directml [DIRECTML_DEVICE]使用 torch-directml，可选指定 DirectML 设备。
--oneapi-device-selector SELECTOR_STRING设置本实例使用的 oneAPI 设备选择字符串。
--supports-fp8-compute让 ComfyUI 表现得像设备支持 fp8 计算。
--enable-triton-backend在 comfy-kitchen 中启用 Triton 后端；启动时默认禁用。
--disable-triton-backend强制禁用 comfy-kitchen Triton 后端，并覆盖 --enable-triton-backend。
--preview-method [none,auto,latent2rgb,taesd]设置采样器节点的默认预览方法，可选 none、auto、latent2rgb、taesd。
--preview-size PREVIEW_SIZE设置采样器节点预览的最大尺寸。
--cache-ram [GB ...]使用 RAM 压力缓存，是默认缓存模式；可传 0 个、1 个或 2 个数值，第一个是活动缓存阈值，第二个是非活动缓存/固定阈值；无值默认活动缓存为系统 RAM 的 10%，最小 2GB、最大 10GB，非活动缓存为系统 RAM 的 100%，最大 128GB。
--cache-classic使用旧式激进缓存。
--cache-lru CACHE_LRU使用 LRU 缓存，最多缓存 N 个节点结果；可能使用更多 RAM/VRAM。
--cache-none减少 RAM/VRAM 占用，但每次运行都会执行每个节点。
--high-ram在高 RAM 系统或偏好使用页面文件而非模型加载的系统上，可能略微提升性能。
--use-split-cross-attention使用 split 交叉注意力优化；使用 xformers 时忽略。
--use-quad-cross-attention使用次二次交叉注意力优化；使用 xformers 时忽略。
--use-pytorch-cross-attention使用 PyTorch 2.0 的交叉注意力函数。
--use-sage-attention使用 Sage Attention。
--use-flash-attention使用 FlashAttention。
--use-ck-attention使用 Comfy Kitchen Attention。
--disable-xformers禁用 xformers。
--force-upcast-attention强制启用注意力 upcasting；如果修复黑图，建议反馈。
--dont-upcast-attention禁用所有注意力 upcasting；除调试外通常不必要。
--enable-manager启用 ComfyUI-Manager 功能。
--disable-manager-ui仅禁用 ComfyUI-Manager 的 UI 和端点；计划安装等后台任务仍会运行。
--enable-manager-legacy-ui启用 ComfyUI-Manager 旧版 UI，隐含启用 --enable-manager。
--gpu-only将所有内容，包括文本编码器/CLIP 模型等，都存储并运行在 GPU 上。
--highvram默认模型使用后会卸载到 CPU 内存；此选项让模型保留在 GPU 内存中。
--lowvram如果启用了动态 VRAM，则此选项无效；如果未使用动态 VRAM，则让文本编码器在 CPU 上运行。
--novram当 --lowvram 不够时使用。
--cpu所有内容都使用 CPU，速度很慢。
--reserve-vram RESERVE_VRAM设置要为操作系统/其他软件保留的 VRAM 数量，单位 GB；默认会根据操作系统保留一定数量。
--vram-headroom VRAM_HEADROOM为 DynamicVRAM 设置额外保留的 VRAM 余量，单位 GB；ComfyUI 会尽量保持这部分 VRAM 完全空闲未使用，即使计入其他应用的 VRAM。
--disable-nvml-pressure使用 CUDA 而不是 NVML 来检测 DynamicVRAM 的内存压力。
--async-offload [NUM_STREAMS]使用异步权重卸载；可选参数控制卸载流数量，默认 2；Nvidia 上默认启用。
--disable-async-offload禁用异步权重卸载。
--disable-dynamic-vram禁用动态 VRAM，改用基于估算的模型加载。
--enable-dynamic-vram在默认未启用动态 VRAM 的系统上启用动态 VRAM。
--fast-disk偏好磁盘后备的动态加载和卸载，而不是未固定 RAM；对快速 NVMe 磁盘用户可能更快。
--disable-cuda-graphs禁用 CUDA Graphs。
--disable-comfy-compiler禁用 Comfy 模型编译器，包括其 CUDA Graph 子功能。
--assert-graph-breaks在 Comfy 模型编译器发生图断裂时失败。
--force-non-blocking强制 ComfyUI 对所有适用张量使用非阻塞操作；在某些非 Nvidia 系统上可能提升性能，但也可能导致部分工作流出问题。
--default-hashing-function {md5,sha1,sha256,sha512}选择用于重复文件名/内容比较的哈希函数，默认 sha256。
--disable-smart-memory强制 ComfyUI 积极卸载到普通 RAM，而不是尽可能将模型保留在 VRAM。
--deterministic让 PyTorch 尽可能使用较慢的确定性算法；注意这可能无法在所有情况下让图像完全确定。
--fast [FAST ...]启用一些未测试且可能降低质量的优化；不带参数启用全部；可指定具体优化，当前有效值包括 fp16_accumulation、fp8_matrix_mult、cublas_ops、autotune。
--debug-hang启用 Ctrl-C 时的堆栈跟踪转储，用于调试挂起问题。
--disable-pinned-memory禁用 pinned memory 使用。
--mmap-torch-files加载 ckpt/pt 文件时使用 mmap。
--disable-mmap加载 safetensors 时不使用 mmap。
--dont-print-server不打印服务器输出。
--quick-test-for-ci用于 CI 的快速测试。
--windows-standalone-buildWindows 独立构建模式，启用独立版常用便利功能，例如启动时自动打开页面。
--disable-metadata禁止在文件中保存提示词元数据。
--disable-all-custom-nodes禁用加载所有自定义节点。
--whitelist-custom-nodes WHITELIST_CUSTOM_NODES [WHITELIST_CUSTOM_NODES ...]指定即使启用了 --disable-all-custom-nodes 也要加载的自定义节点文件夹。
--disable-api-nodes禁用加载所有 API 节点，同时阻止前端与互联网通信。
--multi-user启用每用户存储。
--verbose [LEVEL FILE ...]设置控制台日志；可不带值或带 LEVEL，也可添加 LEVEL FILE 作为日志输出；可重复使用。
--log-stdout将普通进程输出发送到 stdout，而不是默认的 stderr。
--front-end-version FRONT_END_VERSION指定要使用的前端版本；需要联网从 GitHub Releases 查询和下载；格式为 [repoOwner]/[repoName]@[version]，version 可为 latest 或有效版本号。
--front-end-root FRONT_END_ROOT指定前端所在目录的本地文件系统路径，覆盖 --front-end-version。
--user-directory USER_DIRECTORY用绝对路径设置 ComfyUI 用户目录，覆盖 --base-directory。
--models-directory MODELS_DIRECTORY设置 ComfyUI 模型目录，覆盖 --base-directory 中的 models 文件夹。
--enable-compress-response-body启用响应体压缩。
--comfy-api-base COMFY_API_BASE设置 ComfyUI API 的基础 URL，默认 https://api.comfy.org。
--database-url DATABASE_URL指定数据库 URL，例如内存数据库可用 sqlite:///:memory:；默认是有效用户目录下的 comfyui.db。
--enable-assets启用资产系统，包括 API 路由、数据库同步和后台扫描。
--enable-asset-hashing扫描资产时计算 blake3 内容哈希；启用后支持未来资产可移植功能，如去重、跨机器模型解析，但会增加启动成本和大模型目录的输出成本；默认关闭。
--feature-flag KEY[=VALUE]设置服务器功能标志；用 KEY=VALUE 设置显式值，裸 KEY 表示设为 true；布尔值和数字会自动转换；可多次指定，例如 --feature-flag show_signin_button=true 或 --feature-flag show_signin_button。
--list-feature-flags以 JSON 打印已知可通过 CLI 设置的功能标志注册表，然后退出。

多个参数用空格分隔，如 --force-fp16 --bf16-vae --use-pytorch-cross-attention
