# ComfyUI 模型管理器（薇薇的猫）🐱

基于 Flask 的 ComfyUI 一站式管理 Web 应用，内置模型/插件管理、输入输出文件管理、工作流管理、aria2c 下载、抖音素材提取、笔记本、定时关机等功能。

## ✨ 主要功能

- **模型 / 插件管理**：浏览、搜索、筛选、批量新增、删除、Git 一键克隆
- **输入 / 输出管理**：文件浏览、复制、移动、删除、重命名、右键菜单
- **工作流管理**：浏览、编辑、保存、解析引用模型、备份
- **下载引擎**：aria2c 高速多线程下载（断点续传）
- **抖音素材提取**：分享链接提取无水印视频 / 图片
- **其他**：笔记本、定时关机、多用户（用户 / 会员 / 管理员）

## 🚀 快速开始

```bash
git clone https://github.com/wwsmiao/wwdmui.git
cd wwdmui
python -m venv venv
venv\Scripts\activate          # Windows
pip install -r requirements.txt
python run.py                  # 自动打开 http://127.0.0.1:7860
```

首次运行会在项目根目录生成 `settings.json`，可配置 ComfyUI 目录、输入/输出/工作流目录、pip 镜像、关机延迟等；数据库使用 SQLite，无需额外配置。
